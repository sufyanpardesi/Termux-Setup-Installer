# SUFIYAN PARDESI - TERMUX SETUP INSTALLER

## GitHub
Repository: sufyanpardesi/termux-setup-installer
Main installer: sufiyan.sh

## Installation
One-command installation from GitHub.

## Installer-managed directory
$HOME/Sufiyan-Pardesi

Only files and components created or managed by this installer belong here.
Never move the user's personal projects or existing installations into this directory.

## Existing data protection
- Preserve all existing user files, folders, and personal projects.
- Never delete, move, or overwrite user data.
- Never overwrite existing private application configurations.
- Detect and safely reuse compatible software installations.
- Do not reinstall compatible components unnecessarily.
- Back up installer-managed settings before modifying them.
- Never upload private configuration, credentials, PIN data, logs, or backups.

## Existing software detection
Detect and safely reuse compatible installations of:
- OpenCode
- Android SDK
- Android Platform Tools
- Android Build Tools
- Java
- Gradle
- Node.js
- NPM

Install or update only when required and compatible.

## First-run experience
1. Welcome screen and responsive terminal banner.
2. Optional custom display name.
3. Theme selection or default theme.
4. Optional security PIN; disabled by default.
5. Installation summary with verified download size and estimated time.
6. Automated setup after user confirmation.
7. Final report with actual installed sizes and elapsed time.

Use these directories only for installer-managed files and metadata.

## Quality and safety requirements
- ARM64 Termux compatibility must be verified.
- Mobile-friendly terminal interface.
- Safe to rerun and idempotent.
- Real installation and version checks.
- Detailed logs and installation report.
- Backup before modifying installer-managed settings.
- Never claim success when a component test fails.
- No automatic deletion or project relocation.
- No restore feature.
- Private files and runtime data must never enter the public repository.
